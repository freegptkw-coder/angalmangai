# Contributing

Thanks for contributing to Manga Bangla Live!

## Development Setup
1. Install Android Studio.
2. Open the project and sync Gradle.
3. Run `./gradlew :app:assembleDebug` to verify builds.

## Guidelines
- Keep secrets out of code and commits.
- Prefer clear domain interfaces over tightly-coupled UI logic.
- Add tests for new domain logic and repositories where feasible.
- Use meaningful commit messages.

## Reporting Issues
Create an issue with:
- Steps to reproduce
- Expected vs actual behavior
- Logs (remove sensitive info)
